1. КРАТКОЕ ОПИСАНИЕ ЛАУНЧПАДА GEMFUN
--------------------------------------------------------------------------------
GemFun — это фабрика мем-токенов с bonding curve (кривой связывания).
Ключевые особенности:

  • Каждый токен запускается любым пользователем (кнопка "Launch Token")
    за комиссию 0.0001 ETH.
  • Цена токена растёт по кривой по мере покупок.
  • Общая эмиссия кривой: 300 000 000 токенов (CURVE_SUPPLY).
  • Покупки/продажи идут за $HASH — никаких других пар нет.
  • Когда кривая полностью выкуплена (100%), создатель запускает
    миграцию (кнопка TGE): ликвидность уходит в Uniswap V3.
  • После миграции внутри токена открывается "майнинг": пользователи
    стейкают NFT-инструменты (GPU, ASIC, FARM и т.д.) и получают
    награду в токенах из mining reserve (ещё 300 000 000 токенов).
  • Название, символ и лого фиксируются при запуске; создатель может
    менять только ссылки (website/twitter/telegram/discord).
  • У каждого токена есть Founder (адрес создателя).

  Chain:  Base (8453)

Функции агрегатора:
  getCardFeed(token, user)          -> gv (полные данные токена) + ud + балансы/allowances
  getDetail(token, user)            -> gv + ud
  getFeed(offset, limit, sort)      -> список токенов (sort: 0=creation,1=marketcap,2=recent,3=migrated)
  getFeedByMarketCap(offset, limit) -> токены, отсортированные по рыночной капитализации
  getFeedByCreation(offset, limit)  -> токены по времени создания
  getFeedByHolder(user, offset, limit) -> токены, которыми владеет юзер
  getFeedByMiner(user, offset, limit)  -> токены, которые юзер майнит
  getFeedMigrated(offset, limit)    -> только мигрировавшие токены
  getTokenCount()                   -> кол-во токенов

Возвращаемая структура GemView (getCardFeed/getDetail, первое поле):
  token:          address  — адрес мем-токена
  name:           string   — имя токена
  symbol:         string   — символ токена
  logoHash:       bytes32  — хеш лого (keccak256 от ipfs://CID)
  description:    string   — описание, либо "ipfs://CID|описание"
  website/twitter/telegram/guild: string — ссылки
  creator:        address  — адрес создателя (Founder)
  sold:           uint256  — продано токенов на кривой
  raised:         uint256  — суммарно уплачено $HASH
  miningReserve:  uint256  — остаток майнинг-резерва
  isMigrated:     bool     — мигрировал ли токен в Uniswap V3
  isCurveCompleted: bool   — выкуплена ли кривая на 100%

Если хотите читать напрямую из GemFun (без агрегатора):
  getTokenFullData(token) -> TokenCore{name, symbol, logoHash, description} + TokenMetadata + creator + stats[5]
  tokenCore(token)        -> name, symbol, logoHash, description
  tokenMetadata(token)    -> website, twitter, telegram, guild
  tokens(token)           -> migrated, curveCompleted, sold, raised, miningReserve
  tokenCreator(token)     -> адрес создателя
  getTokensPage(offset, limit) -> список адресов токенов

4. ЛОГО ТОКЕНА (КАК ОТОБРАЖАТЬ КАРТИНКУ)
--------------------------------------------------------------------------------
Лого хранится как IPFS CID. Есть два способа его получить:

  1) Из logoHash: это bytes32 = keccak256("ipfs://CID").
     Восстановить исходный URI нельзя (односторонний хеш), поэтому
     используйте способ 2.

  2) Из description (практика проекта): при запуске поле description
     упаковывается как строка:
         "ipfs://<CID>|<текст описания>"
     Пример:
         "ipfs://bafybeig...xyz|Децентрализованный мем-коин"
     Чтобы получить лого: если description содержит "|" и левая часть
     начинается с "ipfs://" (или с "Qm"/"ba" — старые CID) — это лого.

  Показ картинки: замените "ipfs://" на публичный шлюз, например:
     https://gateway.pinata.cloud/ipfs/<CID>
  Если лого не удалось получить — показать fallback (первые буквы символа).

5. ЭКОНОМИКА И BONDING CURVE
--------------------------------------------------------------------------------
Ключевые константы:
  CURVE_SUPPLY      = 300_000_000 * 1e18  (эмиссия кривой, в wei)
  MINING_RESERVE    = 300_000_000 * 1e18  (майнинг-резерв, в wei)
  deployFee         = 0.0001 ETH

Формула цены (функция контракта calculateReserveFor(sold)):
  reserve(sold) = sold/1000 + sold^2 / (45_000_000_000 * 1e18)

Здесь:
  sold  — сколько токенов уже продано на кривой (в wei)
  reserve(sold) — сколько $HASH ушло в резерв при данной sold (в wei)

Оценка цены покупки:
  cost(memeOut) = reserve(sold + memeOut) - reserve(sold)

Оценка выручки от продажи:
  out(memeIn) = reserve(sold) - reserve(sold - memeIn)

Прогресс кривой:  sold / CURVE_SUPPLY * 100 %
Прогресс майнинга: (MINING_RESERVE - miningReserve) / MINING_RESERVE * 100 %

6. КАК СДЕЛАТЬ ПОКУПКУ (ДЛЯ КНОПКИ "КУПИТЬ")
--------------------------------------------------------------------------------
Шаг 1. Approve $HASH (ERC-20 approve) на контракт GemFun:
       HASH = 0xA9B631ABcc4fd0bc766d7C0C8fCbf866e2bB0445
       spender = 0xea4831Df95738d6Ef0f2b47e5345fa75A2E59e86
       amount  = расчётная стоимость + запас (рекомендуется x100 или max)

Шаг 2. Вызов buy на GemFun:
       GemFun.buy(token, memeOut, maxHashIn)
         token    — адрес мем-токена из профиля юзера
         memeOut  — сколько токенов купить (в wei, 18 decimals)
         maxHashIn— максимум $HASH, который готовы потратить
                    (обычно cost * 1.10, т.е. slippage 10%)

Продажа (обратная операция, на тот же контракт):
       Шаг 1: approve мем-токена (spender = GemFun)
       Шаг 2: GemFun.sell(token, memeIn, minHashOut)
         minHashOut = расчётная выручка * 0.90 (slippage 10%)

Decimals токенов: 18 (1e18).

7. СЦЕНАРИЙ "КОРЗИНА/ШКАЛА ПОКУПКИ" В ВАШЕМ ПРОЕКТЕ
--------------------------------------------------------------------------------
Юзер вставляет адрес токена с лаунчпада в свой профиль.
Другие юзеры видят на его странице:

  • Лого токена  (см. раздел 4)
  • Имя токена и символ  (name, symbol)
  • Адрес контракта токена  (полный или 0x1234...abcd)
  • Кнопку "Buy" со шкалой (сколько купить за $HASH):
      - шкала 0–100% (или выбор суммы в токенах / в $HASH)
      - пересчёт: cost(memeOut) по формуле из раздела 5
      - кнопка: approve (если allowance < cost) -> buy
      - показать баланс $HASH и оценку стоимости
  • Ссылку-кнопку "Открыть на hashcoin.farm" -> https://hashcoin.farm/gem
      (для перехода к полному интерфейсу токена)

Примечания:
  • Перед buy проверяйте allowance: ERC20.allowance(user, GemFun).
  • После успешной покупки можно обновить баланс юзера (token.balanceOf(user)).
  • Если token.isMigrated == true, кривая завершена — покупка на лаунчпаде
    недоступна, торги идут на Uniswap V3 (кнопку можно скрыть или вести
    на страницу токена).
  • Если token.isCurveCompleted == true и isMigrated == false — идёт
    подготовка миграции (TGE), покупка в лаунчпаде также заблокирована.
